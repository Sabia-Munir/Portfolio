# Sabia Munir — Portfolio

A modern, professional portfolio website showcasing my work as a UI/UX Designer & Frontend Developer.

## Live Preview

Simply open `index.html` in your browser — no build tools required!

## Features

- Particle background animation
- Typing text effect
- Scroll-triggered animations
- Interactive skill bars
- Project showcases with expandable features
- Timeline experience section
- Contact form with validation
- Fully responsive design
- Glass morphism UI

## Tech Stack

- HTML5
- Tailwind CSS (via CDN)
- Vanilla JavaScript
- Google Fonts (Inter, JetBrains Mono)

## Sections

1. **Hero** — Animated intro with typing effect
2. **About** — Personal info and key highlights
3. **Skills** — Animated skill bars across 4 categories
4. **Projects** — Featured work (CityMind, Cafe Prosa, IVOR)
5. **Experience** — Timeline of journey
6. **Contact** — Contact form and social links

## Deployment

### GitHub Pages
1. Push to a GitHub repo
2. Go to Settings → Pages
3. Select "Deploy from a branch" → main

### Vercel / Netlify
Just connect the repo — zero config needed.
